# Task manager (Flask)

Same Task Manager app. rebuilt with Flask.

## Tech Stack 

- Flask
- postgreSQL
- psycopg 3
- flask-cors
- python-dotenv

## How to Run

```bash
git clone <repo-url>
cd task_manager_flask
pyhon -m venv venv 
./venv/Scripts/Activate.ps1
pip install -r requirements.tst
# setup .env from .env.example
python app.py 

```
